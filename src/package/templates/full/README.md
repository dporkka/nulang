# {{name}}

A Nulang project.

## Structure

- `src/main.nula`   — entry point
- `src/lib.nula`     — library module
- `tests/`           — test files
- `examples/`        — standalone demos

## Commands

```
# Build and type-check
nula build

# Run the entry point
nula run

# Run tests
nula test

# Run a demo
nulang examples/demo.nula
```

## Dependencies

Add dependencies with `nula add <name>`.
