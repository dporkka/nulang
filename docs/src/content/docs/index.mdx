```nulang
actor Counter {
    state count: Int = 0
    behavior inc() { self.count = self.count + 1 }
    behavior get() { self.count }
}
let c = spawn Counter {} in {
    send c inc()    // fire-and-forget
    send c inc()
    ask c get()     // synchronous request → 2
}
```

## Why Nulang?

Building reliable distributed systems today usually means stitching together actors, queues, databases, workflow engines, and observability tools. Nulang integrates those capabilities into the language itself so you can focus on your application logic instead of infrastructure plumbing.

<div class="benefit-row">
  <div class="benefit-text">

### Build software that heals

Nulang's actor model and supervision trees mean failures are isolated and restarted automatically. A bad message or a crashing service doesn't take down the whole system. Durable workflows checkpoint state at each step and use saga compensation to roll back safely when a step fails — your program survives node restarts.

  </div>

### Distribute without rewriting

Actors communicate through location-transparent messages. Move a service from one node to many, and the code stays the same.

## Installation

```bash
# Clone and build from source
git clone https://github.com/nulang-org/nulang.git
cd nulang
cargo build --release

# Start the REPL
cargo run -- --repl
```
